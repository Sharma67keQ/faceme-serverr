# Faceme Branding Notes

## Core mark
- Primary mark: rounded chat bubble with a smiling face
- Mark gradient: purple `#8B5CFF`, blue `#28A7FF`, orange `#FF9B42`
- Canvas color: dark neon base `#0B0B12`
- Use the mark with generous spacing, subtle glow, and no distortion

## Identity direction
- Friendly, modern, social, vibrant, premium, clean
- The logo should feel alive on dark surfaces without becoming flashy or over-lit

- Text base: `#F7F4FF`
- Surface base: `#26213F`

## Usage rules
- Keep the chat-bubble mark on dark or glassy surfaces
- Use the full lockup for auth/onboarding and the compact icon for navigation/loading
- Keep glow subtle and premium
- Avoid treatments that make Faceme feel visually generic or indistinct

## Product application
- Login and onboarding use the full lockup
- Feed and top-level discovery surfaces use the compact lockup
- Buttons, avatars, cards, and borders inherit the neon dark product palette
